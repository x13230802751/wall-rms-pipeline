# 实验记录：自动发现墙面与指定墙面 RMS

日期：2026-11-20。默认流程为 geometry；语义模式仅在合成数据中用已知类别验证接口，不代表训练模型的识别精度。实验脚本和配置随 Git 保存；真实点云、逐点结果及图只留本地。

## 1. 官方房间运行

输入相邻旧项目的 `data/Point_Cloud_Data.zip` 中 M26.pcd（793,393 点）和 M04.pcd（510,190 点），单位 m、up=+Z。没有输入旧四点，没有从官方 RMS 反推区域，没有按真值优化参数。两房间均用 `configs/default.json` 对应的默认配置。

命令：

```powershell
.\run_local.ps1 run --cloud "../project/data/Point_Cloud_Data.zip::M26.pcd" --unit m --walls all --out outputs/M26_v1
.\run_local.ps1 run --cloud "../project/data/Point_Cloud_Data.zip::M04.pcd" --unit m --walls all --out outputs/M04_v1
.\run_local.ps1 measure --catalog outputs/M26_v1/catalog.json --wall W03 --out outputs/M26_W03_selected
```

复跑时使用新输出目录。M26 整体运行约 23.88 秒，M04 约 19.19 秒（含读入、图和逐点文件；单次本机计时，不是性能基准）。各发现四面主要候选。查看 `outputs/*_v1/index.html`、`overview.png` 和 `wall_elevations.png` 可核对位置、形状和开口。

| 房间 | 墙号 | 测量点数 | expanded RMS / mm | paper 对照 / mm |
|---|---|---:|---:|---:|
| M26 | W01 | 53,227 | 5.5795 | 2.5649 |
| M26 | W02 | 132,027 | 4.8830 | 1.4882 |
| M26 | W03 | 138,645 | 1.9579 | 1.2394 |
| M26 | W04 | 109,501 | 5.2473 | 1.1777 |
| M04 | W01 | 117,783 | 4.3296 | 1.4943 |
| M04 | W02 | 46,842 | 12.6892 | 1.9276 |
| M04 | W03 | 47,347 | 7.6151 | 1.5518 |
| M04 | W04 | 115,975 | 1.8981 | 1.4324 |

W01 等编号属于本次目录。单独选择 M26 W03 得到相同的 1.9578794191 mm，验证“先发现，再指定墙号”链路。

图上部分较大偏差集中于开口边缘、底部和突出物附近。几何模式不能确定这些点是缺陷、附属物还是其他表面，因此整墙 RMS 不能直接解释为真实净墙的实体平整度。两种模式差异很大时，应查看点图、接入可靠语义标签或明确局部测区，不能只选更小的数。

**没有把官方 1.0/1.8 mm 绑定到这些墙号。** 官方人工测区、测量方式和独立不确定度未完整确认，以上是自动候选区域的实际测量，不是已证实的真值误差。

## 2. 官方输出独立检查

`scripts/verify_saved_results.py` 对 8 个输出核对：源文件哈希、目录/索引文件哈希、每行原始点编号与 XYZ、不同墙点集不重复，以及逐点距离和 RMS。

独立以协方差最小特征值求 RMS，与 SVD 主程序比较。最大差为约 `2.4483e-10 mm`。这个结果证明数值/文件一致，不能证明墙身份、区域选择或物理测量精度。完整记录见 `results/official_verification.json`。

## 3. 合成整房间基准

`scripts/benchmark.py` 共 14 个场景：四种干净 RMS、25 mm 局部鼓包、两档噪声、两档随机稀疏、局部遮挡、悬空板、近墙杂物（几何/语义两种模式）和旋转重力方向。

13 个场景成功产生结果，共匹配 52 面墙；20% 保留率的稀疏场景未找到可靠地面，明确失败并保留记录。合成点间距、邻域尺度与真实官方数据不同，使用固定合成配置，配置完整记录在每个案例中。

| 场景 | 观察结果 |
|---|---|
| 干净墙 0、0.5、1.8、5 mm | 自动识别四面墙；目标墙 precision/recall 均为 1，恢复 RMS 与设定值一致至数值精度 |
| 25 mm 局部鼓包 | 恢复测量 RMS 5.8927 mm；严格内点对照为 0 mm，显示直接用内点可能遗漏真实缺陷 |
| 噪声 0.5 / 2 mm | 目标墙观测 RMS 约 2.0606 / 2.8316 mm；噪声本身会影响观测指标 |
| 随机保留 50% | 目标墙召回约 97.08%，RMS 差约 0.03075 mm |
| 随机保留 20% | 失败：默认固定邻域参数下无法可靠发现地面 |
| 局部遮挡 | 对剩余观测墙点完成计算，不能说明被遮挡表面的真实形态 |
| 悬空板 | 未作为有效接地墙保留 |
| 近墙杂物，几何模式 | 目标墙真实 RMS 为 0，输出约 8.8464 mm；这是明确的污染失败 |
| 同一杂物，提供正确语义标签 | 恢复 0 mm；标签是合成真值，不是模型预测成绩 |
| 旋转房间并提供正确 up | 识别和计算正常，原始点编号保持 |

用独立协方差特征向量求平面，再计算原始残差 RMS，避免旋转平面接近零特征值开平方的舍入误差。成功场景同一选点集与主程序的最大数值差约 `1.6146e-13 mm`；最大选点误差约 8.8464 mm 来自杂物案例，两者不可混为一谈。

结果在 `results/synthetic_records.json`、`results/synthetic_summary.json`。早期 `outputs/synthetic_benchmark` 保留使用最小特征值直接开平方的记录；正式汇总取 `synthetic_benchmark_v2`，改变的是独立数值核查的稳定性，没有改写实际测量值或隐藏失败案例。

## 4. 自动测试和界面

自动测试覆盖四墙提取、点集合不重复、单位/姿态、非有限坐标索引、鼓包恢复、局部四点、无地面、配置和标签非法输入、杂物语义过滤、文件哈希、指定墙号、拒绝覆盖、毫米输入与批量测量。局部鼓包 ROI 没有严格内点时，主结果仍输出，对照值为空并说明原因。

浏览器测试使用 Edge/Playwright，实际打开生成页面，检查四个选项、下拉和表格选择联动、复制命令、无页面脚本错误以及手机宽度无横向溢出。截图和 QA JSON 保留在本地输出目录。

## 5. 结论边界

已验证完整房间到墙号目录、再到指定墙 RMS 的可运行链路。现有版本适用于已知向上方向、具有可见地面和较大连续平面墙的房间。没有训练神经网络，没有证明复杂房型/家具遮挡下的通用识别能力，也没有完成同测区官方实体真值验证。
